How to write constraints

Constraints can be placed on any column listed below. Supported comparison operators: < > >= <= = !=. Logical operators: and, or.

Separate each constraint with and or or, e.g.:

redshift >= 0 and redshift < 0.4

RM_match = 1 or PSZ2_match = 1

Note: when querying for multiple values in the same column using = or !=, and acts as a delimiter rather than in a strictly logical sense. For example:

classification = 'cluster' and classification = 'not cluster'

returns rows where classification is either ‘cluster’ or ‘not cluster’ — equivalent to using or here.

The wildcard * is supported in text searches, e.g.:

classification = '* cluster'

matches ‘probable cluster’, ‘possible cluster’, and ‘not cluster’ but not ‘cluster’.

notes = '*high-z*'

matches any row where ‘high-z’ appears in the notes field. Wildcard text searches are case-insensitive.
